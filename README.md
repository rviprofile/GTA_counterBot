# TELEGRAM BOT for VOSHOD_SOFT

Телеграм бот сочетает в себе два API телеграма: клиентская часть и бот. А также подразумевает использование стороннего API для вызова тех или иных функций, сохранение практически всего происходящего в базу, а файлов в папку files.

### Запуск
- `npm i`
- `node index.ts`
